# Fluranto - 100+ Free Web Tools & Site Builder

Fluranto is a completely free, privacy-first toolbox for everyday web utilities. 

I built this because I was tired of simple tools adding paywalls, daily limits, or forcing users to create an account. 

🌐 **Official Website:** [https://fluranto.com](https://fluranto.com)

## ⚡ Core Features
- **100% Free:** No hidden fees, no premium tiers.
- **Zero Friction:** No login, no email capture required.
- **Privacy-First:** Most Image and Text tools run locally in your browser. Your files never touch my servers.

## 🛠️ Tools Included
- **PDF Tools:** Merge, Split, Compress, Image to PDF.
- **Image Tools:** Convert (WebP, JPG, PNG), Resize, Crop, Screenshot Beautifier.
- **Text & Dev Tools:** JSON Formatter, Base64 Encode/Decode, Markdown Converters.
- **Page Builders:** Free Waitlist Builder, Bio Link Builder, Coming Soon Pages.

Give it a try at [fluranto.com](https://fluranto.com) and feel free to use the tools whenever you need them. No strings attached.
